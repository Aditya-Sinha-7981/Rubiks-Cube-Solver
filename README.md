# Rubik's Cube Solver
I enjoy solving Rubik's cube and it's different variations, based on my experience with online cube solvers, I have decided to make this project where I can showcase my own variantion of Rubik's Cube Solver

## How It's Made:

**Tech used:** HTML, CSS, JavaScript, Three.js

I have primarily built the Rubik's cube with ![Three.js](https://threejs.org/) and will build the backend(currently work in progress) with the help of python which will have the algorithms for solving the cube
